Fuzzy Sugeno

Metode Perhitungan Deteksi AI

Sistem menggunakan pendekatan Fuzzy Logic Sugeno untuk menggabungkan metrik citra seperti entropy, deteksi tepi, dan noise. Hasilnya dihitung sebagai skor antara 0 dan 1, lalu diubah menjadi persentase untuk menentukan apakah gambar lebih mungkin merupakan hasil AI atau manusia.

  • Entropy → mengukur kompleksitas distribusi piksel.
  • Edge Density → mendeteksi ketajaman dan detail tepi objek.
  • Noise Level → mengukur tingkat gangguan visual citra.
  • FFT Frequency → menganalisis distribusi frekuensi gambar.
  • Texture (GLCM) → menganalisis pola tekstur citra digital.
  • Brightness → mengukur tingkat pencahayaan gambar.
  • Blur Level → mendeteksi tingkat keburaman citra.
  • RGB Consistency → mengukur konsistensi distribusi warna.
  • Histogram Distribution → melihat penyebaran intensitas piksel.
